# Nightly Closeout

Turn leftover end-of-day token and model capacity into safe, unattended overnight Codex/Claude work loops, with active-project triage, guardrails, and a durable objective via Codex Goals.

## Grounding Rules

- Identify the currently active projects from real workspace evidence (entrypoints, boards, docs, inboxes, source-of-truth files) before proposing any overnight work
- Score candidate tasks for value and risk; only queue work that is safe to run unattended
- Generate separate Codex (strategy/review) and Claude (execution/research) loop prompts rather than mixing roles
- By default do NOT send messages, publish, spend money, sign, or delete anything while unattended
- Use Codex Goals to hold one durable objective across the run; fall back to copy/paste prompts when direct Claude dispatch is unavailable
